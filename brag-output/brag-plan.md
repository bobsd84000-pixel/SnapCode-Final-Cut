# SnapCode 3D — Brag Video Plan

**Project:** SnapCode 3D — 3D capture to Three.js code generator  
**Duration:** 18 seconds  
**Format:** Landscape (16:9)  
**Tone:** Polished | Direction: Technical Premium Product  
**Music:** Enabled | SFX: Enabled  

---

## Planning Rubric Answers

1. **What is the app?**  
   A web app that converts 3D captures (from Armorpaint, photogrammetry tools) into production-ready Three.js, Babylon.js, or PlayCanvas code via Claude API.

2. **Funniest/most impressive claim?**  
   "Dépose une capture 3D → Récupère du code Three.js prêt à déployer."  
   (Drop a 3D capture → Get production-ready Three.js code.)

3. **Visual hook?**  
   Premium cobalt/navy palette with gold accents. Live 3D rendering of a polished silver ring with professional studio lighting, rotating smoothly in Three.js.

4. **What to show from UI?**  
   - Drop zone (with animation)
   - 3D preview rotating
   - Code generation moment
   - Generated iframe preview
   - Copy/Share action

5. **Shortest satisfying duration?**  
   18 seconds achieves the full arc without excess.

6. **Tone fit?**  
   **Preset:** Polished  
   **Creative direction:** Technical premium — the kind of elegant, serious product that earns quiet respect.

7. **Audio feel?**  
   Warm, tech-forward music bed (future/ambient style). Subtle UI SFX: soft click on upload, gentle processing tone, satisfying "code ready" sound. No dialogue.

8. **Share caption:**  
   "Snapcode 3D: Turn your 3D captures into Three.js code instantly. Built for artists and developers."

9. **User flow worth showing?**  
   Upload → Processing → 3D Preview Live → Code Generated.
